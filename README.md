# 情绪可视化日记平台

一个智能的情绪管理工具，支持语音文字混合日记，情绪可视化分析，冥想引导等功能。

## 🌟 功能特色

### 📝 智能日记记录
- **语音文字混合输入**：支持语音识别和文字输入
- **情绪标签系统**：7种情绪类型，强度评分
- **拍照记录**：支持拍照记录当下感受
- **标签管理**：自定义标签分类
- **心情评分**：1-10分心情评分系统

### 🧘‍♀️ 冥想引导
- **多种冥想类型**：呼吸冥想、正念冥想、慈心冥想等
- **计时器功能**：可调节的冥想时长
- **呼吸引导**：实时呼吸指导
- **进度统计**：冥想完成率和时长统计

### 📊 数据可视化
- **情绪趋势图**：7天情绪变化趋势
- **情绪分布**：各类情绪占比分析
- **冥想统计**：冥想习惯分析
- **个性化洞察**：基于数据的智能建议

### ⚙️ 个性化设置
- **主题切换**：浅色/深色/自动主题
- **语言支持**：中文/英文界面
- **通知设置**：自定义提醒时间
- **隐私控制**：数据隐私级别设置
- **数据管理**：导出/清除数据

## 🚀 技术栈

- **前端框架**：React 18 + TypeScript
- **构建工具**：Vite
- **状态管理**：Zustand
- **UI组件**：Tailwind CSS + Framer Motion
- **图标库**：Lucide React
- **日期处理**：date-fns
- **路由**：React Router DOM

## 🌈 情绪类型

- 😊 **开心** (happy) - 积极愉快的情绪
- 😢 **难过** (sad) - 悲伤低落的情绪
- 😠 **生气** (angry) - 愤怒不满的情绪
- 😰 **焦虑** (anxious) - 紧张担忧的情绪
- 😌 **平静** (calm) - 安宁平和的情绪
- 🤩 **兴奋** (excited) - 激动兴奋的情绪
- 😐 **一般** (neutral) - 中性平静的情绪
